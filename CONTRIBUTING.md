# Contributing to AgentGuard

Thank you for contributing! Maintainer: **Belfeki.tn**.

1. Open an issue describing the bug or proposed change before large PRs.
2. Fork the repository and create a focused branch.
3. Install: `pip install -e '.[dev]'`.
4. Run: `pytest` and `ruff check .`.
5. Include tests, docs, and a clear PR description.
6. For vulnerabilities, follow SECURITY.md instead of public issues.

Please keep changes small, respect contributors, and avoid claiming security guarantees without tests.
