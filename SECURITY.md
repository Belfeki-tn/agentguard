# Security Policy

AgentGuard is pre-release and **does not yet enforce security controls**.

## Reporting
Do not open public issues for suspected vulnerabilities. Use GitHub's private vulnerability reporting feature if enabled for the repository. If unavailable, contact the maintainer through a privately published security contact channel (to be added before public launch).

## Scope and limitations
The planned proxy only governs calls routed through it. It cannot control direct tool access, a compromised host, or bypasses outside its execution boundary. Keep tool credentials least-privileged.
